Keyboard shortcuts

Alt+Shift+RRead the page · play / pause when already reading
Alt+Shift+SRead selected text
Alt+Shift+EPick an element to read
Alt+Shift+XStop
Alt+Shift+← / →Previous / next sentence (while reading)

Change them at chrome://extensions/shortcuts. Right-click any page for “Read this page”, “Start reading from here”, “Read selection” and “Pick an element”.

About

Powered by Kokoro-82M (Apache-2.0) via Transformers.js and ONNX Runtime Web, with phonemization by the pure-JS eSpeak-NG port phonemizer. Model weights are downloaded once from Hugging Face (onnx-community/Kokoro-82M-v1.0-ONNX) and cached locally. Nothing you read ever leaves your computer.
